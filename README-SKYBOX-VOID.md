# Texture Flow 0.4.0 ? Skybox / Void addition

Start TextureFlow.exe and choose **Skybox / Void**. Try **Show me an example**, then follow Picture ? Opening ? Look ? Apply.

Read **Skybox Void Guide.html** for the illustrated beginner instructions, recipes, every control, troubleshooting and developer handoff. The original T.A.R.D. Manual remains the reference for the original selection/scrolling tools.

This release adds new files only. All 46 pre-existing tracked files remain byte-identical to version 0.3.0, verified by the compatibility manifest. New custom shader effects are PC/Built-in oriented and do not reproduce the original material's shading. Headset appearance and upload require your own avatar/world check.
